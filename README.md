## How to install?

1. Install **NeoForge** for **Minecraft 1.21.1**. Java 21 is required.
2. Download the AtomCraft `.jar` for your Minecraft version.
3. Place it in your `mods` folder. For multiplayer, install it on both the server and the client.
4. Launch the game.
