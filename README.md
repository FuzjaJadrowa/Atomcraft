# SingleloaderModTemplate

My template for creating single-loader mods for Minecraft!

This template features separate branches for different mod loaders:
- [`neoforge`](../../tree/neoforge) - Template for NeoForge mods.
- [`fabric`](../../tree/fabric) - Template for Fabric mods.

## How to use
Clone this repository and checkout the branch for the loader you want to target:
```bash
git clone -b <loader> https://github.com/FuzjaJadrowa/SingleloaderModTemplate.git
```
